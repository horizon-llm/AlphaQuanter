# verl Integration for Stock Trading RL

This directory contains our modifications to [verl](https://github.com/volcengine/verl) at at commit [4ed7811](https://github.com/volcengine/verl/tree/4ed7811813fb7a42c71bc7b20eb2c6d58c4754a4) for stock trading model training with backtesting capabilities.


## Modifications

We have made the following modifications to the base VERL framework:

### New Recipe
- Added custom recipe for stock trading RL training
- Located in: `recipes/stock_trading/`

### Enhanced Ray Trainer
- **Modified file**: `verl/trainer/ppo/ray_trainer.py`
- **Purpose**: Added backtesting functionality during validation phase
- **Changes**: Integrated backtesting logic to evaluate model performance on historical data during training validation

## Data Preparation

### Step 1: Collect Data

First, use the scripts in `data_collection/` to gather all required data (see data_collection README for details).

### Step 2: Convert Data to Pickle

After collecting all CSV and JSON files, convert them to a single pickle file for efficient loading during training:

```bash
python recipe/langgraph_agent/stock_trading/convert_to_pkl.py
```

## Training

### Running the Training Script

```bash
bash recipe/langgraph_agent/stock_trading/run.sh
```

### Backtesting During Validation

During training, the modified `ray_trainer.py` will automatically:
1. Run validation at specified intervals
2. Perform backtesting on validation data
3. Log backtesting metrics (ARR, SR, MDD, etc.)
